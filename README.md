# СкладСкан

> Система подсчёта объёма груза по изображению с камеры на складе

Сайт-презентация командного проекта по дисциплине
**«Проектная деятельность»**. Сам сайт выполнен мной
в рамках дисциплины **«Проектная практика»**.

---

## О проекте

Камера фиксирует груз на складе, алгоритм компьютерного зрения
определяет его габариты, а система вычисляет объём и передаёт
данные в учётную систему (WMS). Цель — убрать ручной обмер
коробов и паллет.

**Целевые показатели:**

| Параметр | Значение |
|---|---|
| Точность габаритов | ± 2 см |
| Время обработки одного груза | ≤ 1,5 с |
| Оборудование | обычная IP-камера |
